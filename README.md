## 三、实现功能

### 1. LED 流水灯

使用三颗 LED 实现流水灯，同一时刻只点亮一颗。

利用 `HAL_GetTick()` 进行非阻塞计时，支持正向、反向、暂停和继续运行。

流水灯切换间隔支持在 100～2000ms 范围内通过串口调整，实验中使用过 500ms、300ms 和 1000ms 等设置。

### 2. 按键控制

通过 GPIO 外部中断实现两个按键控制：

* 按键一：控制流水灯暂停与继续
* 按键二：切换正向与反向
* 实现按键消抖，避免一次按下重复触发
* 暂停时保持当前 LED 状态
* 恢复后按照当前方向继续运行

### 3. 串口数据包控制

使用 USART1 与 USB 转 TTL 模块实现电脑和 STM32 的通信。

串口参数为：

* 波特率：115200
* 数据位：8
* 停止位：1
* 校验位：无

使用串口接收中断接收固定长度数据包，通过结构体进行数据解析，并检查帧头、参数及校验和。

**数据包格式：**

`AA RUN DIR STEP_L STEP_H CHECK`

各字段含义：

| 字段     | 含义             |
| ------ | -------------- |
| AA     | 固定帧头           |
| RUN    | 00 暂停，01 运行    |
| DIR    | 00 正向，01 反向    |
| STEP_L | 时间间隔低字节        |
| STEP_H | 时间间隔高字节        |
| CHECK  | 前五个字节累加后取低 8 位 |

校验规则：

`CHECK = (AA + RUN + DIR + STEP_L + STEP_H) % 256`

例如，设置流水灯运行、正向、500ms：

`AA 01 00 F4 01 A0`

设置流水灯暂停、正向、500ms：

`AA 00 00 F4 01 9F`

错误帧头或错误校验和的数据包不会改变当前运行状态。

### 4. OLED 状态显示

使用软件 I²C 驱动 OLED 显示屏。

OLED 实时显示：

* STATE：运行或暂停状态
* DIR：正向或反向
* STEP：流水灯切换间隔
* LED：当前点亮的 LED 编号

按键或串口指令改变运行状态后，OLED 同步更新。

### 5. 串口状态反馈

使用 `HAL_UART_Transmit_IT()` 通过 USART1 中断发送状态反馈。

反馈采用英文文本格式：

`STATE=%s,DIR=%s,STEP=%u,LED=%u\r\n`

例如：

`STATE=RUN,DIR=FWD,STEP=500,LED=1`

各字段含义：

* STATE：RUN 表示运行，PAUSE 表示暂停。
* DIR：FWD 表示正向，REV 表示反向。
* STEP：流水灯切换间隔，单位为毫秒。
* LED：当前点亮的 LED 编号，取值为 1～3。

每条反馈以 `\r\n` 结束。

程序使用 `snprintf()` 生成反馈字符串，并通过 `HAL_UART_Transmit_IT()` 异步发送。当按键操作或有效串口指令触发状态反馈时，电脑可以接收到当前运行状态。

4. 串口控制运行与暂停
5. 串口控制流水方向
6. 串口调整流水灯切换间隔

## 六、实验总结

本次实验综合使用 GPIO、外部中断、串口通信、数据包解析、软件 I²C 和 OLED 显示等知识，完成了流水灯的多方式控制。

通过使用 `HAL_GetTick()` 实现非阻塞计时，使程序能够在流水灯运行期间及时处理按键和串口事件。

通过串口中断接收数据包并进行校验，实现了电脑对流水灯状态、方向和切换间隔的控制，同时利用串口中断发送运行状态反馈。

经过调试，最终实现了 LED、OLED 和电脑串口状态的同步。
